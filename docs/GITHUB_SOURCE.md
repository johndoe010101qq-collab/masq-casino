# Исходники MASQ на GitHub

Репозиторий: [johndoe010101qq-collab/masq-casino](https://github.com/johndoe010101qq-collab/masq-casino). Доступ закрытый. Проверяющим площадки доступ отдельно не предоставлялся.

В состав входят клиент React/Vite, игровые изображения и шрифты, математические движки, серверная админка Node.js 24 / SQLite, тесты, описание механик и примеры размещения. Frontend и административный сервер находятся в одном репозитории. Финансовый игровой сервер, реальные платежи и вывод АР не реализованы.

Исходники перенесены отдельным снимком текущих рабочих файлов, включая новую локальную админку. Исходная история управляемого проекта не переносится. `github-source-manifest.json` фиксирует базовый commit, SHA-256 и Git blob SHA каждого перенесённого файла; базовый commit не выдаётся за commit этого репозитория.

Исключены реальные `.env`, токены, локальная SQLite-база и sidecar-файлы, зависимости, сборки, архивы и служебные файлы хостинга. `.env.example` содержит только публичный App ID, локальные значения по умолчанию и пустые поля секретов. Токен приложения и точный `accountId` владельца настраиваются приватно при отдельном развёртывании сервера.

Публичный [сайт Cloudflare Pages](https://masq-casino.pages.dev/) остаётся прежним статическим DEMO. Загрузка исходников на GitHub не обновляет его и не подключает серверную админку к настоящим ставкам. Порядок запуска локального сервера описан в [SERVER_ADMIN.md](SERVER_ADMIN.md).

`server-admin-verification.json` и более ранние квитанции сохраняют состояние на момент соответствующей проверки. Их поля `repositoryUploaded:false` или прежние упоминания отменённой передачи являются историческими записями. Согласование SPWorlds, проверка настоящего iframe и предоставление доступа проверяющему остаются отдельными действиями.

Старый `scripts/package-review-source.mjs` относится к предыдущему выпуску и требует чистого исходного checkout. Для этого переноса использован отдельный экспорт рабочих файлов; архив этого репозитория можно получить штатной кнопкой GitHub **Code → Download ZIP**.
